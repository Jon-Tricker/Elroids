What is 'Elroids'?

Elroids ia a prototype, opensource, 3D, javascript/threeJS based cross between 'Asteroids' and 'Elite'.

No install is required, It can be launched here.

Any comments gratefully recieved. There is a facebook discussion group here.

There is a, currently private, github repository see the 'Developer Notes'. for more detail.
